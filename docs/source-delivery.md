本仓库集中保存当前项目的前后端源码。后端位于根目录，前端位于 `frontend/`，两者分别保留自己的许可证、依赖声明、测试和构建配置。

## 来源

- 后端基于 `jxxghp/MoviePilot` v2.15.6，上游提交 `684e76e`。
- 前端基于 `jxxghp/MoviePilot-Frontend` v2.15.6，上游提交 `19cead06f72c859732afdeccea7a37c0a770a947`。
- 保留现有项目修改，包括后端可选外部资源配置及 GDrive 挂载目录处理能力，以及前端 GDrive 任务管理页面。后续增量补齐目录扫描、离线分类、独立多账号 API 上传、上传后同盘分类归档及本地资料后处理。
- 仓库不包含服务器数据库、运行配置、SSH 密钥、依赖安装目录或生产构建产物。

## GDrive 页面范围

管理用户可从“整理 → Google Drive”访问 `/gdrive`。当前前端提供目录任务、执行记录、归档规则、文件任务和独立直接上传；支持配置编辑、目录浏览、只读预览、二次分类导入与编辑、任务详情及上传重试／取消。临时文件清理仍通过后端接口操作。详情见 `frontend/docs/gdrive.md` 及 `docs/mcp-api.md`。

新安装默认关闭。管理员可配置已有挂载目录，或配置独立 OAuth 上传账号、共享盘暂存和最终归档目标。API 上传先核验上传文件，再在同盘移动至最终分类目录，核验后才生成 STRM、复用 NFO／图片并定向扫库。挂载复制进度不能作为云端同步完成的证明。运行凭据与正式目录配置不随源码发布。
