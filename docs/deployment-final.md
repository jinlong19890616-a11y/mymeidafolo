# 最终部署与迁移说明

本说明记录当前部署方式及验收边界，不包含生产配置、账号密码、数据库、OAuth、站点 Cookie、媒体或私有插件包。

## 发布内容

- 既有 GDrive 上传核验、同盘分类归档、STRM 和本地资料处理。
- 持久化 Telegram 阶段通知及每24小时上传汇总。
- 插件同步保护：设置进程环境变量 `MOVIEPILOT_PLUGIN_SYNC_DISABLED=true` 后，`PluginManager.sync()` 在查询市场、读取配置和安装前直接返回，保留迁移的定制插件。
- 未设置或设置为 `false` 时，继续原有同步行为。该开关不关闭插件加载，也不拦截管理员主动调用的安装接口；缺失依赖安装和本地开发热同步不是该开关控制的范围。
- 该保护此前由只读文件覆盖部署，本次纳入正式源码；在使用本次源码重新构建镜像后，才能移除旧覆盖挂载。不要把旧镜像直接改成没有覆盖文件。

## 内网部署

容器与下载器、Emby 接入已有 Docker bridge 网络，不发布宿主机端口。为实例分配同网段内未占用的固定 IP，网页容器端口为 `3000`。

```yaml
services:
  mymeidafolo:
    image: ${MYMEDIAFOLO_IMAGE:?请设置已构建的镜像}
    restart: unless-stopped
    env_file:
      - ./private/app.env
    environment:
      MOVIEPILOT_PLUGIN_SYNC_DISABLED: "true"
    volumes:
      - ./private/config:/config
      # 媒体目录、迁移插件、下载器路径等按实际容器路径另行挂载。
    networks:
      media_net:
        ipv4_address: ${MYMEDIAFOLO_INTERNAL_IP:?请设置同网段空闲地址}
networks:
  media_net:
    external: true
```

示例不提供公开镜像地址，也不是包含所有媒体挂载的完整恢复文件。构建镜像必须包含前后端产物及原部署所需的运行资源。进程监听地址不能写为宿主机公网地址。

仅在运行库中保留一个指定管理员，保留原密码摘要和权限；不要把账号数据库或凭据写进镜像、Git 或示例环境文件。删除其他账号前先备份并检查其关联数据。

## 1Panel 反代与 HTTPS

- 1Panel/OpenResty 反代目标使用 `http://容器内网IP:3000`；代理必须能路由到该 Docker 网络。
- 域名 HTTPS 在反代入口终止。Cloudflare 使用“完全（严格）”时，源站证书必须有效、链完整，并覆盖访问域名。
- 526 是 Cloudflare 对源站证书校验失败；更改容器内网地址不能修复域名不匹配的证书。为该域名单独绑定正确证书，不覆盖其他网站证书。
- 不发布容器端口只代表后端内网化。公开域名反代仍是公网入口；若要求仅本人访问，另设 VPN、访问控制或 Cloudflare Access。

## 迁移与回退原则

1. 旧实例运行时先做一致性快照、配置与插件私有备份；按新库表结构迁移旧业务，保留新云盘表、任务和通知回执。
2. 保留原订阅、站点、下载与整理历史、分类及目录路径。逐行对照，并保留新实例自己的历史记录及其引用。
3. 数据核验通过后才停止旧实例；退出时再取最终快照核对增量。无遗漏后才启用新实例调度，且仅一套 Telegram 接收。
4. 旧容器不删除并禁止自动双开。回退前先停新实例并规划保留切换后的新增记录，不能直接覆盖或丢弃。

当前版本的安全模式会跳过启动阶段调度，但查询后台服务可能惰性构建调度器；不要将它视为所有接口都不能启动任务的强隔离措施。迁移核验时不要访问后台调度接口或手动触发真实下载、整理。
